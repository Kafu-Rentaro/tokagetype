# tokagetype

2D・3Dプロトタイピングツール（ブラウザ版）。Figma のように画面をデザインして操作を試せることに加え、3D モデルの配置・カメラ切替、ツール内でのスカルプト造形、Blender / Unity との GLB 受け渡しに対応します。詳細仕様は [docs/SPEC.md](docs/SPEC.md) を参照してください。

## 起動方法

Node.js 20 以降が必要です。

```bash
npm install
npm run dev        # 開発サーバー（http://localhost:5173）
npm run build      # 型チェック + 本番ビルド（dist/）
npm run preview    # ビルド結果のプレビュー（http://localhost:4173）
npm test           # Vitest 単体テスト（文書モデル / Action 検証 / 履歴）
```

公開版は GitHub Pages でも試せます（後述「GitHub Pages での公開」）。

## サンプルの試し方

初回起動時にサンプルプロジェクト（スマホ商品紹介画面）が自動で用意されます。

1. 画面右上の **▶ 再生** を押すと再生モードになります。
2. **「背面を見る」ボタン** を押すと、3D ビューのカメラが背面プリセットに切り替わります（「前面を見る」で戻ります）。
3. 詳細フレームへの画面遷移ボタンも配置されています。遷移先では **⤺ 開始フレームに戻る** で戻れます。
4. **✎ 編集** で編集モードに戻ります。編集後にブラウザを再読み込みしても、モデル・ボタンの位置・操作の関連は復元されます（IndexedDB に自動保存）。

## 編集モードの基本操作

- **フレーム（画面）**: 左パネルで追加・削除・選択ができます。再生開始フレームも指定できます。既定サイズはスマホ画面（390×844）です。
- **ノードの追加**: ツールバーから rect（矩形）/ text（文字）/ button（ボタン）/ view3d（3D ビュー）を追加できます。
- **ノードの編集**: 中央の Konva キャンバス上で選択・移動・リサイズ・回転ができます。レイヤー一覧（左パネル）で並び替え・表示切替も可能です。
- **プロパティ**: 右パネルで位置・サイズ・色・テキストなどを編集します。テキストはキャンバス上のダブルクリックでも編集できます（日本語入力対応）。
- **キーボード**: Ctrl+Z / Ctrl+Shift+Z で Undo / Redo、Delete で削除。複製はツールバーから行います。
- **クリック時操作（Action）**: 任意のノードに、右パネルの Action 編集から以下を設定できます。
  - `setCamera` — 指定した 3D ビューのカメラをプリセットに切り替える
  - `navigate` — 再生中の表示フレームを切り替える
  - `toggleVisible` — 指定ノードの表示/非表示を切り替える
  - `openUrl` — URL を開く
  - 参照先が存在しない Action は警告表示され、再生時は無視されます。

## 3D ビューと GLB

- **取り込み**: 3D ビューを選択し、右パネルの「GLB ファイルを選択…」から .glb を選ぶか、ファイルをキャンバスへドラッグ&ドロップします。取り込んだ GLB はアセットとして保存され、他の 3D ビューからも再利用できます。
  - Blender / Unity から書き出した .glb がそのまま表示できます。複数メッシュ・テクスチャ埋め込み・KHR マテリアル拡張を含む実モデルでも、モデル全体が収まるよう自動でフィットして表示されます。
- **カメラ**: front / back のプリセットが既定で用意されます。プロパティパネルでプリセットの追加や「現在の視点を保存」ができます。編集時に 3D ビュー内の視点を回すには、そのビューの「3D操作」を有効にしてください（ノードのドラッグ操作と競合するため既定は無効です）。
- **書き出し**: 右パネルの「GLB 書き出し」で、選択中アセットを .glb ファイルとしてダウンロードできます（スカルプト結果の書き出しもこちらから）。

## 再生モード

- **▶ 再生** で開始フレームから実行します。ボタンをクリックすると設定した Action（カメラ切替は約 0.6 秒の補間でアニメーション、フレーム遷移、表示切替、URL を開く）が動作します。
- 再生中の状態は文書に保存されません。**✎ 編集** でいつでも編集に戻れます。

## スカルプト

1. 3D ビューを選択し、右パネルの **🗿 スカルプト** を開きます（組み込みの球プリミティブで始めることもできます）。
2. ブラシは **pull（引き出す）/ push（押し込む）/ smooth（滑らか）** の3種。半径と強さを調整できます。
3. **1 ストローク = 1 Undo** 単位です（Ctrl+Z で戻せます）。
4. 「適用して保存」を押すと、造形結果が GLB 化されてアセットを置き換えます。再読み込み後も造形が残ります。GLB 内の対象は最初のメッシュで、それ以外のメッシュ（画面・レンズ等）は保持されます。

## プロジェクトの保存と受け渡し

- **自動保存**: 編集内容は IndexedDB へ自動保存されます（編集後 500ms デバウンス）。保存状態は画面右上に表示されます。
- **複数プロジェクト**: ツールバーから新規作成・切り替え・削除ができます。
- **.tokage ファイル**: プロジェクト全体を `.tokage`（zip: doc.json + assets/*.glb）として export / import できます。別の環境へプロジェクトを渡すときはこちらを使ってください。

## GitHub Pages での公開

`main` ブランチへの push で、GitHub Actions（`.github/workflows/pages.yml`）が `npm ci && npm run build` を実行し、GitHub Pages へ自動デプロイします。

初回だけ、リポジトリ側で以下の設定が必要です。

1. GitHub のリポジトリページで **Settings > Pages** を開く
2. **Build and deployment** の Source を **GitHub Actions** にする
3. `main` へ push するとワークフローが走り、https://kafu-rentaro.github.io/tokagetype/ で公開されます

ビルド時は環境変数 `VITE_BASE=/tokagetype/` を指定して配信パスに合わせています（`vite.config.ts` 参照）。ローカル開発では未指定で `/` になるため影響ありません。
